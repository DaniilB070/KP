Разрабатываемая программа должна:

Вычислять по соответствующей формуле.

Выводить результат каждого преобразования.

Рассчитывать среднее арифметическое и медиану первых 20 преобразованных значений.

Выводить результаты статистического анализа.

Обеспечивать корректное выполнение вычислений и понятный вывод результатов на экран.
