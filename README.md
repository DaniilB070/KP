# Курсовой проект: «Цифровой двойник технологического процесса»
 
**Вариант 25.** Мониторинг реактора: температура сырья
 
---
 
## 1. Назначение проекта
 
Программа моделирует цифровой двойник технологического процесса мониторинга температуры сырья в реакторе.  
На вход поступают измерения температуры \( X \) (°C).  
По индивидуальной формуле вычисляется показатель \( Q = f(X) \).  
Затем выполняется оперативный контроль (сравнение с верхней границей UCL) и статистический анализ первых 20 значений \( Q \).
 
---
 
## 2. Входные данные
 
| Параметр              | Значение                          |
|-----------------------|-----------------------------------|
| Параметр              | Температура сырья (\( X \))       |
| Единица измерения     | °C                                |
| Диапазон \( X \)      | 10 … 70                           |
| Штатный режим         | 25–45 °C                          |
| Количество измерений  | \( N = 50 \)                      |
 
Значения \( X \) вне диапазона 25–45 °C рассматриваются как отклонение технологического режима.
 
---
 
## 3. Индивидуальная формула \( Q = f(X) \)
 
\[
Q(X) =
\begin{cases}
3 \cdot (X - 25) + 10, & \text{если } X < 25 \\[6pt]
2 \cdot \sqrt{X - 25} + 45, & \text{если } 25 \le X \le 45 \\[6pt]
\dfrac{(X - 45)^2}{4} + 55, & \text{если } X > 45
\end{cases}
\]
 
**Ограничения:** \( 10 \le X \le 70 \).
 
---
 
## 4. Ручной расчёт (проверочные примеры)
 
| \( X \) (°C) | Формула                              | \( Q \)     |
|--------------|--------------------------------------|-------------|
| 20.00        | \( 3\cdot(20-25)+10 = -15+10 \)      | **–5.00**   |
| 43.00        | \( 2\cdot\sqrt{43-25}+45 = 2\cdot\sqrt{18}+45 \) | **53.49** |
| 50.00        | \( (50-45)^2/4 + 55 = 25/4 + 55 \)   | **61.25**   |
 
Контрольный пример из задания:  
\( X = 43.00 \) °C → ожидается \( Q = 53.49 \).
 
---
 
## 5. Оперативный контроль
 
- Верхняя граница: **UCL = 64.32**
- Если \( Q > \) UCL → состояние **АВАРИЯ**
- Иначе → состояние **НОРМА**
 
(Названия состояний выбраны студентом самостоятельно.)
 
---
 
## 6. Статистический анализ
 
Для первых 20 значений \( Q \):
- среднее арифметическое;
- медиана (на этапе КТ1 — заглушка, будет реализована позже).
 
---
 
## 7. Структура программы (КТ1)
 
Программа **не использует массивы**.  
Все вычисления выполняются «на лету» в цикле по одному измерению.
 
### Функции:
 
| Функция                  | Назначение                                      |
|--------------------------|-------------------------------------------------|
| `read_X(int number)`     | Чтение одного значения температуры \( X \)      |
| `calculate_Q(double X)`  | Расчёт \( Q = f(X) \) по формуле варианта 25    |
| `control_and_state(double Q)` | Сравнение с UCL и вывод состояния          |
| `statistics(double sum)` | Вывод среднего (медиана — заглушка)             |
 
### Блок-схемы преобразования данных (описание)
 
**Схема 1 (основной поток):**  
`X → f(X) → Q → CONTROL → STATE`
 
**Схема 2 (статистика):**  
`Q[1..20] → заданный интервал → STATISTICS`  
(среднее накапливается без массива, медиана — на следующих этапах)
 
---
 
## 8. Как собрать и запустить
 
```bash
gcc main.c -o twin -lm
./twin
```
 
Программа запросит 50 значений \( X \) и для каждого выведет \( Q \) и состояние.
