# Курсовой проект: «Цифровой двойник технологического процесса»
 
**Вариант 25.** Мониторинг реактора: температура сырья
 
---
 
## 1. Название и назначение проекта
 
**Название:** Цифровой двойник технологического процесса  
 
**Назначение:** программа моделирует мониторинг температуры сырья в реакторе.  
На вход поступают 50 измерений температуры \( X \) (°C).  
По индивидуальной формуле вычисляется показатель \( Q = f(X) \).  
Выполняется проверка технологического режима (25–45 °C) и оперативный контроль по верхней границе UCL.  
После сбора данных рассчитываются среднее и медиана первых 20 значений \( Q \).
 
**Формулировка индивидуального варианта:**  
Вариант 25 — Мониторинг реактора: температура сырья.
 
---
 
## 2. Входные данные
 
| Параметр              | Значение                                      |
|-----------------------|-----------------------------------------------|
| Параметр \( X \)      | Температура сырья                             |
| Единица измерения     | °C                                            |
| Диапазон \( X \)      | 10 … 70                                       |
| Штатный режим         | 25–45 °C                                      |
| Количество измерений  | \( N = 50 \)                                  |
| Окно статистики       | первые 20 значений \( Q \)                    |
 
**Что означает \( X \):** температура сырья, поступающего в реактор.  
**Какие значения поступают в программу:** пользователь вводит 50 вещественных чисел в диапазоне 10…70 °C.  
Значения вне интервала 25–45 °C — технологическое отклонение.  
Значения вне 10…70 — ошибка ввода (повторный запрос).
 
---
 
## 3. Индивидуальная формула \( Q = f(X) \)
 
\[
Q(X) =
\begin{cases}
3 \cdot (X - 25) + 10, & \text{если } X < 25 \\[8pt]
2 \cdot \sqrt{X - 25} + 45, & \text{если } 25 \le X \le 45 \\[8pt]
\dfrac{(X - 45)^{2}}{4} + 55, & \text{если } X > 45
\end{cases}
\]
 
**Ограничения на \( X \):** \( 10 \le X \le 70 \).
 
---
 
## 4. Ручной расчёт \( Q \) для 2–3 значений \( X \)
 
| \( X \) (°C) | Подстановка в формулу                                      | \( Q \)     |
|--------------|------------------------------------------------------------|-------------|
| 20.00        | \( 3\cdot(20-25)+10 = 3\cdot(-5)+10 = -15+10 \)             | **−5.00**   |
| 43.00        | \( 2\cdot\sqrt{43-25}+45 = 2\cdot\sqrt{18}+45 \approx 2\cdot 4.2426+45 \) | **53.49** |
| 50.00        | \( (50-45)^{2}/4 + 55 = 25/4 + 55 = 6.25+55 \)              | **61.25**   |
 
**Контрольный пример из задания:**  
\( X = 43.00 \) °C → ожидается \( Q = 53.49 \).
 
---
 
## 5. Оперативный контроль и состояния
 
1. **Технологический режим** (по \( X \)):
   - \( 25 \le X \le 45 \) → штатный технологический режим
   - иначе → технологическое отклонение
 
2. **Контроль UCL** (по \( Q \)):
   - UCL = 64.32
   - \( Q > \) UCL → **Авария**
   - иначе → **Норма**

## 7. Структура программы
 
### Константы
 
```c
#define UCL     64.32
#define X_MIN   10
#define X_MAX   70
#define N       50
#define N_STAT  20
```
 
### Функции
 
| Функция                         | Назначение                                              |
|---------------------------------|---------------------------------------------------------|
| `calculate_q(double x)`         | Расчёт \( Q = f(X) \) по формуле варианта 25            |
| `check_control(double q)`       | Возвращает 1 (авария), если \( Q > \) UCL, иначе 0      |
| `calculate_mean(double q[])`    | Среднее арифметическое первых 20 значений \( Q \)       |
| `calculate_median(double q[])`  | Медиана первых 20 значений \( Q \) (после сортировки)   |
 
Прототипы объявлены перед `main`.  
Массив `q_values[N]` хранит все 50 значений \( Q \) для последующей статистики.
 
---
 
## 8. Как собрать и запустить
 
```bash
gcc main.c -o twin -lm
./twin
```
 
Программа запросит 50 значений \( X \) (с проверкой диапазона 10…70).  
Для каждого измерения выводится \( Q \), технологический режим и результат контроля UCL.  
В конце — среднее и медиана первых 20 значений \( Q \).
 
**Контрольный пример:**
```
Введите температуру X (от 10 до 70): 43
Рассчитанное Q: 53.49
Штатный технологический режим.
Контроль UCL: норма.
```
