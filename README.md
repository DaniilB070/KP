## 1. Название и назначение проекта

**Название:** Цифровой двойник технологического процесса  

**Назначение:** программа моделирует мониторинг **содержания воды** в реакторе.  
На вход поступают измерения \( X \) (%). По индивидуальной формуле вычисляется показатель \( Q = f(X) \).  
Выполняется проверка технологического режима (5–18 %) и оперативный контроль по верхней границе UCL.  
После измерений рассчитываются среднее и медиана по окну \( Q[31..43] \).

**Формулировка индивидуального варианта:**  
Вариант 55 — Мониторинг реактора: содержание воды.

---

## 2. Входные данные

| Параметр              | Значение                                      |
|-----------------------|-----------------------------------------------|
| Параметр \( X \)      | Содержание воды                               |
| Единица измерения     | %                                             |
| Диапазон \( X \)      | 0 … 50                                        |
| Штатный режим         | 5–18 %                                        |
| Количество измерений  | \( N = 70 \)                                  |
| Окно статистики       | \( Q[31..43] \) (13 значений)                 |

**Что означает \( X \):** содержание воды в реакторе (в процентах).  
**Какие значения поступают:** 70 вещественных чисел. Значения вне 5–18 % — технологическое отклонение.

---

## 3. Индивидуальная формула \( Q = f(X) \)

\[
Q(X) =
\begin{cases}
3 \cdot (X - 5) + 10, & \text{если } X < 5 \\[8pt]
2 \cdot \sqrt{X - 11.5 + 6} + 45, & \text{если } 5 \le X \le 18 \\[8pt]
\dfrac{(X - 18)^{2}}{2} + 55, & \text{если } X > 18
\end{cases}
\]

Упрощение среднего участка: \( 2 \cdot \sqrt{X - 5.5} + 45 \).

**Ограничения на \( X \):** \( 0 \le X \le 50 \).

---

## 4. Ручной расчёт \( Q \) (проверочные примеры)

| \( X \) (%) | Подстановка                                              | \( Q \)     |
|-------------|----------------------------------------------------------|-------------|
| 4.00        | \( 3\cdot(4-5)+10 = -3+10 \)                             | **7.00**    |
| 16.70       | \( 2\cdot\sqrt{16.70-5.5}+45 = 2\cdot\sqrt{11.2}+45 \)   | **51.69**   |
| 20.00       | \( (20-18)^{2}/2 + 55 = 4/2 + 55 \)                      | **57.00**   |

**Контрольный пример из задания:**  
\( X = 16.70 \) % → ожидается \( Q = 51.69 \).

---

## 5. Оперативный контроль

- Верхняя граница: **UCL = 62.90**
- Если \( Q > \) UCL → **ТРЕВОГА**
- Если \( Q \le \) UCL, но \( X \) вне 5–18 % → **ПРЕДУПРЕЖДЕНИЕ**
- Иначе → **НОРМА**

---

## 6. Статистический анализ

Для \( Q[31..43] \) (13 значений):
- **среднее** — накоплением суммы;
- **медиана** — после сортировки окна из 13 значений.

## 7. Структура программы (КТ1)

### Принципы

- Разделение UI и логики: `calculate_Q`, `check_control` — чистые функции.
- Весь ввод/вывод — в `main` (или в функциях интерфейса).
- Прототипы объявлены перед `main`.
- Константы через `#define`.
- Интерфейс на русском языке.

### Константы

```c
#define UCL            62.90
#define X_NORMAL_MIN    5.0
#define X_NORMAL_MAX   18.0
#define N_MEASUREMENTS 70
#define STAT_FROM      31
#define STAT_TO        43
```

### Функции

| Функция                    | Назначение                            |
|----------------------------|---------------------------------------|
| `calculate_Q(double x)`    | \( Q = f(X) \) по формуле варианта 55 |
| `check_control(...)`       | НОРМА / ПРЕДУПРЕЖДЕНИЕ / ТРЕВОГА      |
| `validate_X(double x)`     | Проверка диапазона 0…50               |
